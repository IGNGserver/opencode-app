## 本次更新

### 可靠性与协议

- 修复跨服务器切换时凭据继承和异步响应覆盖新选择的问题；连接、项目和会话状态现在按来源隔离。
- 完善 OpenCode V2 表单、权限和消息契约，避免不支持的请求被错误重试。
- 加固离线缓存删除竞态、过期状态恢复和通知操作；读取失败时保留最近状态，不再误报任务完成。
- 伴随服务改为持久有序投递；注册、撤销、重试和去重在失败或重启后保持一致。

### 固定发布签名

- Release APK 使用固定证书签名，并在发布前验证证书指纹和非 debuggable 状态。证书 SHA-256：`C2:12:EF:1E:68:0C:C1:24:F6:87:9A:CD:B4:62:58:EC:EB:AD:B0:F5:3B:BD:E2:77:16:20:AA:23:AC:D7:AB:D2`。
- `v0.1.0-rc.1` 至 `rc.3` 使用了不同的临时 debug 签名。首次升级需先保存服务器配置，卸载旧包后安装本版；后续版本可用同一证书直接更新。
