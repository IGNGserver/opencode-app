## 本次更新

### 修复：添加服务器时报 "string cannot be converted to jsonobject"

- 修复添加/编辑服务器时，若所填地址返回的不是 OpenCode 接口数据（例如误填了 OpenCode **网页界面地址**、被代理拦截页接管、或服务器返回空响应），表单直接弹出系统原始异常 `Value ... of type java.lang.String cannot be converted to JSONObject` 的问题。
- 现在所有服务器响应解析失败都会给出可自查的中文提示：
  - 返回 HTML 页面 →「服务器返回的是网页而非 OpenCode 接口数据，请确认填写的是 API 地址（不要使用网页界面地址）」；
  - 返回其它非 JSON 文本 →「服务器返回的数据不是有效 JSON，可能被代理拦截或该地址不是 OpenCode 服务」；
  - 空响应 →「服务器返回了空响应，请确认地址指向 OpenCode 服务端口」。
- 原始解析异常仅作为诊断原因链保留，不再向用户展示，也不会在提示中回显整段响应内容。
- 影响范围仅为 `OpenCodeApi` 网络响应解析边界；请求构造、协议检测与凭据逻辑不变。
