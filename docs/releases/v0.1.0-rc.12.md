## 本次更新

### 灵动岛：全服务器任务总览与多品牌适配

- **统一计数口径**：灵动岛不再只显示单个会话的一行详情，而是显示全服务器范围的统一摘要
  「`xx` 个运行中，`xx` 个已完成」；存在需要你处理的任务时追加「`xx` 个待回复」，
  存在失败任务时单独追加「`xx` 个失败」。
  - **待回复** = 等待权限确认 + 等待回答问题。
  - **已完成 / 失败按“未读”统计**：打开对应会话后即视为已读、不再计入；该会话再次跑出新的
    完成或失败结果时会重新计为未读。
- **App 内灵动岛**：不再要求先选中会话，只要有运行中 / 待处理 / 未读结果就常驻顶部；
  点击优先跳转到需要回复的会话，其次是未读的完成或失败结果。
- **系统通知与 Android 16 实时更新**：新增单条常驻的「任务总览」通知，携带状态栏 chip 短文案，
  等待处理类通知也可被系统提升为 Live Update。
- **多品牌灵动岛适配框架**：按「能力探测 + 品牌兜底」路由，单个厂商通道异常不会影响通知本体。
  - **小米 HyperOS 3 超级岛 / 焦点通知**：已接入并补充协议版本与焦点权限探测。
  - **vivo / iQOO OriginOS 原子岛**：新增接入（原子通知参数，未获权限时自动退化为普通通知）。
  - **Android 16 Live Updates**：新增标准通道探测与授权引导，设置页可跳转开启「实时更新」。
  - **OPPO ColorOS 16 流体云**：官方已声明完整兼容 Android 16 Live Updates API，随标准通道生效。
  - **荣耀灵动胶囊 / OPPO ColorOS 15 流体云**：预留可插拔接入骨架与持久化开关，默认关闭，
    待厂商权限与合作参数就绪后开启即可启用。
- **App 被杀后仍能刷新计数**：配置 companion + FCM 后，后台推送会重建并更新任务总览，
  计数不再随进程被杀而停滞。未改动 FCM 载荷与签名，也无需重装或升级服务端插件。
- **设置页新增「灵动岛适配」分区**：逐个通道显示 `已就绪 / 待授权 / 不支持` 与说明，
  并提供待合作通道的开关。
- 品牌接入矩阵、逐通道启用步骤与真机验收清单见 `docs/ISLAND_ADAPTATION.md`。

## 已知限制

- **未在实体设备上验收**：小米超级岛、vivo 原子岛、Android 16 实时更新与 OPPO ColorOS 16 流体云、
  以及后台计数链路都需要真机确认；本仓库的构建与单测只能证明代码可编译与逻辑一致。
- **需要厂商权限**：小米焦点通知、vivo 原子岛（公测）、荣耀白名单、OPPO ColorOS 15 `serviceId`
  都要向厂商申请；未获批时对应通道退化为标准通知，应用侧无法自证可用。
- 荣耀与 OPPO ColorOS 15 目前只有接入骨架，未接真实厂商协议，开关默认关闭。
- 后台计数只覆盖**产生过推送的会话**；App 被杀期间完成但服务端未投递的事件不会计入。
- 华为实况窗需要鸿蒙原生工程，Android 安装包无法使用，明确不在支持范围内。
- 本次为预发布版本，签名与产物命名遵循 `docs/RELEASE_POLICY.md`。
