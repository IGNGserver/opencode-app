## 本次更新

### 修复：支持识别并连接托管 Web 前端的 OpenCode V2 实例

当 OpenCode 实例开启了 Web 前端（例如通过 `opencode serve` 启动，同时提供 API 与 Web SPA 界面）时，客户端探测旧版路径 `/global/health` 会被服务端的 SPA 单页路由拦截并返回 `HTTP 200 text/html`。此前客户端在此处直接抛出「服务器返回的是网页而非 OpenCode 接口数据」，导致中断连接，未能继续尝试 V2 API 探测。

- 现在当探测旧版 `/global/health` 返回 HTML 或 404 时，客户端会自动放行并进入 V2 协议探测流程（`/api/health` 与 `/api/info`），恢复对包含 Web 前端的标准 V2 实例的正常连接。
- 新增单元测试 `detectsV2WhenLegacyPathReturnsSpaHtml`，验证旧版探测返回 HTML 时能够正确识别并连接 V2 实例。

### 体验：服务器地址输入框引导提示与占位示例

- 在添加/编辑服务器表单中，地址输入框在为空时显示灰体示例占位符：`http://192.168.1.x:4096 或配对链接`。
- 输入框下方新增说明文案，明确提示手机无法直接通过 `localhost` 访问电脑，引导用户填写电脑的局域网 IP（如 `http://192.168.1.100:4096`）或直接粘贴电脑端 `opencode pair` 命令生成的免密配对链接。
