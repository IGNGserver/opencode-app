## 本次更新

### 统一 Android 客户端图标

- 启动器、圆形启动器、小米超级岛和通知大图标统一使用新的 OpenCode Mobile 图标。
- 新图标延续 Guanlan 的深色、克制轻拟物设计语言，使用全幅深色背景、低饱和蓝紫主体和轻微哑光立体感。
- 普通 Android 通知使用同一主体的白色单色版本，适配系统对通知小图标的 alpha 蒙版规则，避免彩色图标显示为实心方块。
