## 本次更新

- 信息架构围绕 Server → Project/Directory → Session → Conversation 重构：一级导航改为「会话 / 活动 / 设置」，删除工作台 Dashboard（焦点看板、运行中/待处理/历史三个大数字、智能开工舱），状态统一附着在会话上。
- 会话成为默认首页：顶部优先展示「需要处理」「正在运行」的会话，其余按项目 / 目录分组；条目清晰表达标题、所属项目、状态与相对时间（多服务器时含 Server），并支持搜索。
- 顶栏保留服务器全局选择器（● 名称 ▾）；右上角「＋」新建会话改为底部弹层，一步选择 Server、项目 / 目录、Agent、模型并输入第一条任务后直接开跑（新增 `startSession`）。
- 新增「活动」页：需要处理（授权 / 提问就地回复）、正在运行（含已运行时长）、最近完成，用于跨项目快速处理 Permission / Question 与查看任务状态，不是统计面板。
- Chat 始终是会话主界面：顶部显示会话标题、项目、服务器与运行状态；工具调用默认是一行紧凑执行轨迹（Read / Edit / Bash，点按展开输入输出）；待办 / 改动 / 子任务 / 文件改为会话上下文摘要入口（底部弹层），不再与对话平级分 Tab；Text / Reasoning / Diff / Permission / Question 能力保持不变，Diff 保留逐行着色的移动端阅读体验。
- 返回栈契约同步更新：对话详情 → 所属标签页 → 会话首页 → 交给系统退出（`AppBackStack` 与单测同步调整）。
