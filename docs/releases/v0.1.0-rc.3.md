## 本次更新

本版基于一次全仓库工程审计的修复，覆盖正确性、推送安全、流式性能与结构清理。

### 正确性修复

- 修复 OpenCode ID 被双重 URL 编码的问题：会话/权限 ID 含空格等字符时会请求到错误路径，现在按段精确编码一次。
- 修复后台通知操作可能静默失效的问题：原先在系统给广播接收器的约 10 秒预算内使用了 60 秒超时，现改为 8 秒并在失败时用新连接重试一次。
- 修复伴随服务对任意 idle 事件都推送“任务已完成”的问题（重启后会误报），并补齐 `session.aborted` 的处理。
- 修复伴随服务一次磁盘写入失败后永久无法再保存设备注册的问题。
- 修复删除服务器可能清空另一台服务器“记住的项目/会话”的问题。

### 安全

- 后台推送（FCM）新增 HMAC 校验：伴随服务使用共享密钥签名，App 校验失败即忽略，防止伪造任务通知。服务器资料新增“推送校验密钥”字段。
- 配对链接强制 HTTPS（本机回环除外），并校验重定向目标，避免一次性凭据经明文泄露。
- 通知的“允许/拒绝/停止”操作改走统一的控制器路径，App 内状态即时同步。

### 性能与稳定性

- 流式响应不再是每收到一小段就整段重取会话：改为只就地更新对应消息片段，显著降低流量、解析与加密开销。
- 共享 OkHttp 连接池/调度器，减少握手与闲置线程。
- 离线缓存的加解密移出主线程，避免长会话卡顿。
- 发送任务的锁只覆盖必要区间，慢刷新不再阻塞后续发送。
- 增加轻量日志，便于定位此前静默失败的路径。

### 结构与体验

- 界面改版：工作台/会话/设置的新信息架构、根导航动画与更顺滑的会话进出。
- 采用官方 `opencode pair` 配对链接的一键配置与剪贴板识别。
- 抽取共享的 Keystore 加解密、集中 V1/V2 能力判断，删除死代码并修正文档。
