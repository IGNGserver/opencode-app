## 本次更新

### 视觉：移除全部液态玻璃效果，全面回归纯粹小米 HyperOS / MIUIX 原生规范

彻底移除仿 iOS 的 Liquid Glass（液态玻璃）光学系统，回归纯正、克制、低功耗的小米 HyperOS / MIUIX 官方设计语言：

- **移除 backdrop 依赖与离屏渲染**：
  - 从 Gradle 依赖中完全移除 `io.github.kyant0:backdrop`；
  - 彻底清除 `drawBackdrop` 背景采样、透镜折射（`lens`）、色彩增艳（`vibrancy`）与色散（`chromaticAberration`）计算管线，杜绝不必要的 GPU 与离屏缓冲开销。
- **全新纯正 MIUIX 导航 Dock（`MiuixNavigationDock`）**：
  - 替换原先的悬浮液态 Dock，采用符合 HyperOS 规范的实体 Squircle 卡片与层次表面色（`surfaceContainerHighest`），搭配平滑的微压交互反馈。
- **全面替换灵动岛、轻提示与输入舱**：
  - 任务指示舱升级为遵循 MIUIX 设计语言的实体卡片 `MiuixTaskIsland`，搭载语义呼吸指示灯；
  - 全局轻提示升级为高对比度实体提示条 `MiuixToastHost`；
  - 会话输入舱重构为纯正卡片质感的 `MiuixChatComposer`，快捷操作胶囊与一键触底 FAB 均改为实体 MIUIX 卡片组件。
