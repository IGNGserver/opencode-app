## 本次更新

- 首个 OpenCode Mobile Android 预发布版本。
- 使用 Fluent 2 风格完成首页、服务器、会话、对话和设置页面。
- 支持多服务器 Basic Auth、Android Keystore 凭据保护、SSE 实时状态、任务发送、Agent/Model 选择、权限和问题处理。
- 支持 Todo、子任务、改动、文件浏览、文件搜索、会话 Fork、分享、总结、撤销和删除。
- 增加运行中、待处理和完成通知、Android Live Updates 请求、小米超级岛参数适配，以及可选 FCM companion。
- 增加加密离线缓存，并在离线时显示明确状态、缓存消息和禁用写操作。
