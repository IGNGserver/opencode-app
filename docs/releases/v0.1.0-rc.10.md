## 本次更新

### 全面落地 Liquid Glass（液态玻璃）设计系统

- **核心渲染管线**：引入 `io.github.kyant0:backdrop` 背景采样着色器引擎，彻底告别原先静态低透明度渐变模拟，打通真正的背景实时捕获、大半径高斯毛玻璃模糊（`blur`）与基于 AGSL 的 SDF 透镜几何折射（`lens`）。
- **穿透式 Liquid Glass 悬浮底栏（Dock）**：
  - 全新设计独立物理 Dock（`LiquidGlassDock`），彻底移出阻断滚动的传统 Scaffold 槽位。
  - 支持全屏视口内容穿透，任务与会话列表向下滚动时，文字和卡片在 Dock 底部清晰透射并伴随透镜物理折射，达到与社区标杆（mizuku）一致的显著视觉体验。
  - 搭载弹簧物理滑动选中指示块与柔和环境阴影。
- **顶部实时运行状态灵动岛（`LiquidTaskIsland`）**：
  - 任务执行时从顶部轻巧滑入，呈现伴随微光脉冲呼吸动效的液态玻璃水滴胶囊。
  - 智能感知执行状态（Agent 思考中、工具调用中、等待审批/提问、完成或失败），点击可直接定位到当前任务对话。
- **全局液态玻璃悬浮轻提示（`LiquidToastHost`）**：
  - 替代系统传统弹窗与吐司，采用半透明高斯模糊连续曲率胶囊，支持自动淡出收起与快捷点击关闭。
- **输入舱与操作组件玻璃化**：
  - 会话页输入舱（Composer Dock）及 `@文件`、`/命令`、`Agent` 切换胶囊全面应用液态玻璃材质。
  - 会话流长列表新增液态玻璃回到底部水滴 FAB 按钮，滚动离开底部时自动浮现，点击平滑飞回最新消息。

## 已知限制

- 背景实时采样折射对设备 GPU 及 Android 系统版本（推荐 Android 12+ / API 31+）有一定要求，在较低版本或低算力设备上会自动优雅降级为半透明微晶质感。
