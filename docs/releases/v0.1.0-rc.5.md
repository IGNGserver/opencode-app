## 本次更新

### 视觉与界面重构 (MIUIX + Liquid Glass)

- **视觉语言（形）**：
  - 接入小米 HyperOS 官方经典科技蓝 `#3482FF` 语义调色板，全面淘汰旧版风格；
  - 核心界面几何采用连续曲率圆角 Squircle（Continuous Curvature Rounded Rectangle）；
  - 统一规范排版体系至 `MiuixTheme.textStyles`。
- **信息层级与架构（构）**：
  - 页面结构重构为 MIUIX 官方 `Scaffold` 脚手架框架；
  - 工作台首页引入大标题动态折叠应用栏 `TopAppBar(largeTitle = "任务工作台")`，绑定 `MiuixScrollBehavior` 滚动响应；
  - 任务会话列表采用分段 `TabRow` 统一分类过滤；
  - 任务会话详情划分「对话、待办、改动、文件、子任务」视图，信息密度更清晰。
- **组件语义规范（件）**：
  - 全面使用 MIUIX 官方组件：`Card`、`Button`、`TextButton`、`IconButton`、`TextField`、`InfiniteProgressIndicator`；
  - 接入高级扩展组件：`SuperSwitch`、`SuperArrow`、`SuperDialog` 与 `SuperBottomSheet`。
- **交互与状态反馈（交）**：
  - 交互卡片全面接入 MIUIX 官方物理按压下沉反馈（`PressFeedbackType.Sink` 与 `showIndication`）；
  - 引入语义化状态胶囊（`MiuixStatePill`），统一管理空闲、思考中、工具调用、等待授权、提问及断连状态。
- **动效系统（动）**：
  - 列表全量集成 MIUIX 弹性阻尼越界回弹（`overScrollVertical`）；
  - 会话详情进出采用平滑水平推移与淡入淡出（`slideInHorizontally + fadeIn` / `slideOutHorizontally + fadeOut`）。
- **材料与响应式适应（适）**：
  - **Liquid Glass 材质**：在悬浮导航栏、活动任务 Live Task Surface 与底部输入舱注入真实微光透镜高光、双层轮廓与弹性交互；
  - **多端响应式适应**：手机窄屏（`< 640dp`）使用悬浮式 `Liquid Glass Floating Navigation Bar`；平板与宽屏（`>= 640dp`）自适应左侧 `NavigationRail` 导航侧栏；
  - **深浅色自适应**：通过 `OpenCodeMiuixTheme` 与 `ThemeController` 全链路打通深浅色主题无缝切换。
