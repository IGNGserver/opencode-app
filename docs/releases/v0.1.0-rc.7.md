## 本次更新

### 修复「添加服务器」点击无反应

- 修复进入 App 后服务器管理弹层始终不出现、点击“添加服务器”没有任何反应的问题。该问题导致新用户无法添加任何服务器，等于无法使用本 App。
- 原因是服务器管理与全局提示两个弹层被声明在 MIUIX `Scaffold` 作用域之外：MIUIX 弹层只向 `Scaffold` 提供的状态容器注册，并且只由 `Scaffold` 自带的弹层宿主渲染，作用域之外的弹层会落进无人渲染的列表。现已将两个弹层移入正确作用域。

### 修复返回 / 侧滑手势直接退出应用

- 修复所有页面缺少层级返回、用侧边手势或返回键都会直接退出应用、而非返回上一级的问题。
- 现在具备完整的应用内返回层级：**对话详情 → 所属标签页 → 工作台 → 退出应用**。只有在工作台时才会退出。
- 修复预见式返回（Predictive Back）：返回手势进行中会实时预览上一级页面，对话详情随手指位移并露出底层的会话/设置页面；手势取消时平滑回弹。
- 修复聊天页内 MIUIX 弹窗（重命名、删除、权限、文件引用等）按返回键时可能抛异常崩溃的问题。根因是弹层返回依赖 `androidx.navigationevent` 的调度器所有者，而该能力需要 Activity 1.12 及以上才由 `ComponentActivity` 实现；项目此前固定在 1.10.1。现已升级到 `androidx.activity:activity-compose:1.12.0`，并在清单中显式开启 `enableOnBackInvokedCallback`。
- 修复打开 MIUIX 弹层时点击外部关闭、按返回键关闭不生效或状态残留的问题。

## 已知限制

- 本版不包含 Firebase FCM 配置材料，后台推送仍仅在前台活跃时派发系统通知；仅填写伴随服务地址无法启用编译期未编入的 FCM 能力。
- 完整的手势动画预览与跟手回弹需要在支持 Predictive Back 的 Android 版本（Android 13+ 且系统开启预测性返回；Android 15+ 系统动画默认开启）上才能获得最佳效果。
- 验证环境缺少 KVM 硬件加速，仅在软件模拟器上完成了“弹层可弹出 / 返回键关闭弹层”的实测；多步点按的“标签页返回工作台”路径在当前环境不稳定，已由单元测试覆盖，建议在真机或带硬件加速的环境复验。
- 未在真实 OpenCode Server、真实 Android 设备、真实 FCM 投递与各品牌定制系统上完成验收。
