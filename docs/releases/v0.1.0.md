## 已知限制

- 当前产物不含 FCM。后台推送需要后续包含 Firebase 配置的构建；配置伴随服务地址无法启用本产物缺少的 FCM 能力。前台实时同步不依赖 FCM。
- 尚未在目标 OpenCode Server 和努比亚 Z70 Ultra 刷澎湃 3 上完成验收。返回手感、ROM 的系统提交阈值、动画、键盘/弹层顺序、字体放大及实际布局需要真机确认。
- 本轮独立 API 30/36 模拟器因主机磁盘空间不足启动失败，未运行 Compose UI 自动化或截图验收；构建与 JVM 测试不代表这些体验已通过。
- 权限撤销、分享、结构化附件、worktree 操作、弱网恢复、杀进程后的状态及真实推送仍需目标环境联调。
- 任务计数只能沿已取得的父链聚合；首次仅收到子任务后台消息且未取得父子身份时，当前推送协议无法完整聚合摘要。
- 荣耀和 OPPO 通道仍未实现。远程 Markdown 图片提供打开链接，不自动携带服务器凭据下载。
